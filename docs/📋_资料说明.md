## 🔬 Rev H vs Rev I 差异详解

### 1. Errata 勘误表 — 最大区别

| | Rev H | Rev I |
|------|:--:|:--:|
| 第 33 章 Errata | ✅ 有 | ❌ 已移除（独立发布） |

**Rev H 勘误表中的已知问题（部分）**：
| 编号 | 问题简述 | 修复状态 |
|:--:|------|:--:|
| [1] | `ConfigureFmInterrupt` API 参数边界为 4 字节而非 8 字节 | 无硅修复，有 workaround |
| [2] | SMPU/MPU/PPU 保护区域限制为 2 GB | 无硅修复，有 workaround |
| [3] | `DirectExecute` API 参数在 SRAM 中可能返回错误 | 无硅修复，有 workaround |
| [4] | CAN FD RX FIFO top pointer 在 FIFO 大小为 1 时不正常 | 无硅修复，有 workaround |
| [5] | CAN FD debug 消息状态机在 INIT 时未复位 | 无硅修复，有 workaround |
| [6] | TPIU 外设 ID 不匹配 | 无硅修复 |
| [7] | CAN FD 同 Message ID 多 Tx Buffer 消息顺序反转 | 无硅修复，有 workaround |
| [8] | CAN FD 同 Message ID 多 Buffer 发送描述不完整 | TRM 已更新 |
| [9+] | 更多 Flash / CAN / 系统相关问题 | 详见文档 |

### 2. 文档勘误修正（Rev H → Rev I）

| 修改位置 | 旧 (Rev H) | 新 (Rev I) | 类型 |
|----------|-----------|-----------|:--:|
| CM0+ 向量表基址寄存器 | `CM0_VTOR`（Arm 系统空间） | `CPUSS_CM0_VECTOR_TABLE_BASE`（CPU 子系统） | 修正 |
| 封装图标注 | TEQFP | LQFP | 修正 |
| 电源引脚 VCCD 描述 | "Driven by LDO regulator" | "Driven by internal LDO / external LDO/PMIC" | 修正 |
| 电气章节 27.2 标题 | "Device-level specifications" | "Recommended operating conditions" | 标题互换修正 |
| 电气章节 Table 29 标题 | "Recommended operating conditions" | "Device-level specifications" | 标题互换修正 |
| PLL/FLL 描述 | "±2% frequency error" | "small amount of frequency error" | 措辞优化 |

### 3. 参数更新（Rev H → Rev I）

| 参数 | Rev H | Rev I | 变化 |
|------|:--:|:--:|:--:|
| 订货编号部分料号 | ...Q**0**... | ...Q**1**... | 更新 |
| **RθJA 144-LQFP** | 20.5 °C/W | **24.7 °C/W** | ⚠️ 上升 |
| **RθJA 100-LQFP** | 22.7 °C/W | **28.5 °C/W** | ⚠️ 上升 |
| **RθJB 100-LQFP** | 13.8 °C/W | **20.8 °C/W** | ⚠️ 大幅上升 |
| SPI SCLK 脉宽 | 仅 Typ 值 | 新增 Min/Max 约束 | 更严格 |

> ⚠️ **注意**：封装热阻参数在 Rev I 中全面上调，做热设计时请使用 Rev I 数据！
