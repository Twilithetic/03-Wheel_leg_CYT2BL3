# 嵌入式调试工具链概念笔记

> 别再搞混软件和硬件啦！

---

## 一、完整链条

```
  👩‍💻 VSCode / GDB              ← IDE / 调试器前端
        │  TCP :3333
        ▼
  🧠 OpenOCD / pyOCD            ← GDB Server / 调试服务器（软件！）
        │  通过 libusb/WinUSB
        ▼
  🔌 WCH-Link / J-Link          ← Debug Probe / 调试探针（硬件！）
        │  SWD(JTAG) 两根线
        ▼
  💾 CYT2BL3 芯片               ← 目标 MCU
```

## 二、术语对照表

### 硬件

| 名称 | 准确度 | 谁在用 |
|------|--------|--------|
| **Debug Probe**（调试探针） | ⭐⭐⭐ 最准 | ARM 官方、CMSIS-DAP 规范 |
| **Debug Adapter**（调试适配器） | ⭐⭐⭐ 很准 | OpenOCD 术语（`adapter speed`） |
| **Programmer**（编程器） | ⭐⭐ 还行 | 芯片厂商文档，侧重烧录 |
| **Debugger**（调试器） | ⭐⭐ 常用 | 口语，大家都能懂 |
| **烧录器** | ⭐ 口语 | 不专业但对方能懂 |

### 软件

| 名称 | 准确度 | 说明 |
|------|--------|------|
| **GDB Server** | ⭐⭐⭐ 最准 | OpenOCD 的核心功能：提供 GDB 调试端口 |
| **Debug Server** | ⭐⭐⭐ 很准 | 同上 |
| **Flash Programmer** | ⭐⭐ 还行 | 侧重烧录功能 |
| **烧录软件** | ⭐ 口语 | 不专业 |

### 常见软件一览

| 软件 | 语言 | 支持的硬件 |
|------|------|-----------|
| **OpenOCD** | C + Tcl | J-Link, ST-Link, CMSIS-DAP, KitProg3, FTDI... |
| **pyOCD** | Python | CMSIS-DAP |
| **probe-rs** | Rust | CMSIS-DAP, J-Link, ST-Link... |
| **J-Link Commander** | C（SEGGER 私有） | 仅 J-Link |
| **STM32CubeProgrammer** | C（ST 私有） | ST-Link, 串口 |

### 常见硬件一览

| 硬件 | 协议 | 厂商 | 特点 |
|------|------|------|------|
| **WCH-Link** | CMSIS-DAP v2 | 沁恒 WCH | 便宜（~10 元），缺 Test Mode acquire |
| **J-Link** | 私有协议 | SEGGER | 贵但稳定，高速 |
| **KitProg3** | CMSIS-DAP + 扩展 | Infineon | 随 CYT2BL3 板子附带，有 Test Mode acquire |
| **ST-Link** | 私有协议 | ST | 随 STM32 板子附带 |
| **DAP-Link** | CMSIS-DAP v1/v2 | ARM 开源 | 标准 CMSIS-DAP 实现 |

## 三、OpenOCD 关键术语

你在 OpenOCD 输出里经常看到的词：

| 术语 | 含义 | 示例 |
|------|------|------|
| **adapter** | 调试探针（硬件） | `adapter speed 2000` |
| **target** | 目标芯片 | `targets traveo2_be_4m.cpu.cm4` |
| **interface** | 探针配置文件 | `-f interface/cmsis-dap.cfg` |
| **transport** | 调试协议 | `transport select swd` |
| **flash bank** | Flash 存储区域 | `flash bank traveo21_main_cm0 ...` |
| **work area** | 调试用 SRAM 区域 | 给 flash driver 放算法代码 |
| **DP** | Debug Port | SWD/JTAG 的调试端口 |
| **AP** | Access Port | 内存/系统总线访问端口 |
| **DAP** | Debug Access Port | DP + AP 的总称 |

## 五、SWD vs JTAG

```
都是 ARM 调试协议，走同一组物理引脚：

┌──────────┐          SWD(2线)         ┌──────────┐
│  Probe   │  SWCLK ───────────────→   │  Target  │
│          │  SWDIO ←─────────────→   │          │
└──────────┘                           └──────────┘

┌──────────┐          JTAG(4线)        ┌──────────┐
│  Probe   │  TCK  ────────────────→   │  Target  │
│          │  TMS  ────────────────→   │          │
│          │  TDI  ────────────────→   │          │
│          │  TDO  ←────────────────   │          │
└──────────┘                           └──────────┘

Cortex-M 芯片几乎都用 SWD（省引脚、够用）
JTAG 更多出现在 FPGA 和 Cortex-A 上
```

## 六、常见连接问题的排查顺序

```
1. USB 线插好了吗？          → 设备管理器里能看到 probe
2. SWD 线接对了吗？          → SWCLK + SWDIO + GND（共地！）
3. 芯片供电了吗？            → 目标板有电
4. 驱动装对了吗？            → libusb/WinUSB/zadig
5. probe 支持这个协议吗？    → CMSIS-DAP / J-Link / ST-Link 各有不同
6. OpenOCD 配置对了吗？      → -f 指定的 .cfg 文件里 chip 对了吗
```
