> 当前项目编译方式速查，方便新项目复用。

## 编译器

| 项目 | 内容 |
|------|------|
| **编译器** | `arm-none-eabi-gcc`（GCC ARM Embedded） |
| **来源** | EIDE (Embedded IDE) 内置工具链 |
| **路径** | `C:/Users/29344/.eide/tools/gcc_arm/bin/` |
| **配套** | `arm-none-eabi-size`、`arm-none-eabi-objcopy` |

---

## 编译参数

```
-mcpu=cortex-m4          # ARM Cortex-M4F
-mthumb                  # Thumb-2 指令集
-mfloat-abi=hard         # 硬浮点 ABI
-mfpv=fpv4-sp-d16        # 单精度 FPU
-std=c11                 # C11 标准
-O0 -g3                  # 无优化，完整调试信息
-Wall -Wextra            # 全量警告
-ffunction-sections      # 函数独立段
-fdata-sections          # 数据独立段
-fno-common              # 禁用 common 段
-D__CORTEX_M4 -DCYT2BL3  # 预定义宏
```

链接参数：

```
-T src/cyt2bl3_flash.ld       # 链接脚本
-nostartfiles                  # 不用标准启动文件
--specs=nano.specs             # newlib-nano
--specs=nosys.specs            # 无系统调用
-Wl,--gc-sections              # 去死代码
-Wl,--print-memory-usage       # 打印内存用量
```

## 构建系统

**手写 GNU Makefile**，只有两个命令：

| 命令 | 作用 |
|------|------|
| `make build` | 编译 → 链接 → 生成 `.elf` `.hex` `.bin` |
| `make clean` | 删除 `build/` 目录 |

### 产物

```
make build
  ├── build/firmware.elf    ← probe-rs 烧录用这个
  ├── build/firmware.hex
  └── build/firmware.bin
```

---

## 烧录 & 调试

全部走 **probe-rs**（不在 Makefile 里），通过 VS Code tasks.json 一键完成：

| 操作 | 方式 |
|------|------|
| 编译+烧录 | VSCode → `Ctrl+Shift+B` → `🔥 probe-rs download (flash)` |
| probe-rs 配置 | `.probe-rs.toml`（`chip = "CYT2BL3BAS"`, `protocol = "swd"`） |

---

## 新项目复用 checklist

1. 确认 EIDE 工具链路径 `C:/Users/29344/.eide/tools/gcc_arm/bin/` 存在
2. 复制 Makefile，修改：
   - `CPU_FLAGS`（换 CPU 核时改 `-mcpu` `-mfpu`）
   - `C_DEFS`（芯片宏）
   - `-T` 链接脚本路径
   - `C_SRCS` / `ASM_SRCS` 源文件列表
3. 复制 `.vscode/tasks.json`，改 probe-rs 的 `--chip`
4. 复制 `.probe-rs.toml`，改 `chip` 字段
